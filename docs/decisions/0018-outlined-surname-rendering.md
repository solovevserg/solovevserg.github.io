# Устранение артефактов обводки фамилии в Hero-секции

- Статус: реализовано
- Дата: 2026-04-19

## Контекст

В `SectionHero.vue` фамилия «Соловьёв» отображается как outlined-текст:

```css
.hero__name-line--accent {
    color: transparent;
    -webkit-text-stroke: 1.5px var(--text);
}
```

Размер шрифта — `clamp(3.8rem, 8vw, 7.5rem)`, `font-weight: 900`, шрифт — Inter.

**Причина артефактов.** `-webkit-text-stroke` рисует обводку **по центру** контура глифа:
половина толщины — снаружи, половина — внутри залитой области. Когда `color: transparent`,
заливки нет, и обводка видна изнутри тоже. В сложных глифах Inter (особенно кириллических:
«С», «О», «Ё», «в», «л») внутренние сегменты пути пересекаются между собой при обводке —
в этих точках полоска обводки одного контура накладывается на полоску другого, образуя
видимый крест или пятно.

Проблема усугубляется большим `font-weight: 900`: в кондесированных жирных начертаниях
сегменты глифов расположены ближе и пересечения шире.

## Движущие факторы

- Визуальное качество: outlined-текст — ключевой декоративный элемент Hero; артефакты
  бросаются в глаза и снижают первое впечатление
- Смена шрифта должна затрагивать только эту надпись, не влияя на остальной UI (Inter остаётся)
- Шрифт должен поддерживать кириллицу
- Решение должно работать в обеих темах и на всех размерах экрана

## Технические варианты

### Вариант A — Уменьшить толщину `stroke` (паллиатив)

Сократить `1.5px` до `0.5–0.8px`. Пересечения становятся менее заметны, но не исчезают.

**Плюсы:** одна строка CSS, ноль зависимостей.

**Минусы:** не решает проблему; на больших экранах (7.5rem = ~120px) артефакты всё равно
видны; тонкая обводка теряется на фоне.

---

### Вариант B — SVG-текст с `paint-order: stroke fill`

Заменить `<span>` на `<svg><text>` и использовать `paint-order`:

```vue
<svg class="hero__name-svg" aria-label="Соловьёв">
    <text
        y="1em"
        fill="var(--bg)"
        stroke="var(--text)"
        stroke-width="3"
        paint-order="stroke fill"
    >{{ t('hero.name_last') }}</text>
</svg>
```

`paint-order: stroke fill` рисует обводку первой, затем заливает поверх неё фоновым цветом —
внутренние артефакты перекрываются заливкой.

**Плюсы:** технически корректное решение; шрифт остаётся Inter; работает с CSS-переменными тем.

**Минусы:**

- `fill: var(--bg)` — сплошной цвет. Hero-фон — `dot-bg` (точечный паттерн), поэтому буквы
  окажутся с непрозрачной заливкой и будут выглядеть «вырезанными» из фона — видна
  прямоугольная область заливки вокруг каждой буквы.
- SVG-`<text>` сложнее верстать в потоке (нужно вручную задавать `width`/`height`, выравнивание);
  адаптивный `font-size: clamp(...)` не работает напрямую на SVG-текст без дополнительного JS.
- Текст остаётся в Inter 900 — сами пересечения контуров никуда не деваются, они просто
  скрыты заливкой; при наведении/анимации может мелькнуть.

---

### Вариант C — Сменить шрифт только для этой надписи _(рекомендуется)_

Подключить отдельный display-шрифт с геометрическими монолинейными глифами, у которых нет
внутренних пересечений контуров. Применить только к `.hero__name-line--accent`.

**Критерии выбора шрифта:**

- Геометрический или гуманистический sans-serif с простыми, «открытыми» глифами
- Поддержка кириллицы
- Хорошо смотрится в outlined-варианте (широкие контрштрихи, одинаковая толщина линий)
- Доступен для самохостинга (woff2, подключается как ADR 0017)

**Кандидаты:**

| Шрифт          | Характер                        | Кириллица | Вес репозитория   |
| -------------- | ------------------------------- | --------- | ----------------- |
| **Unbounded**  | геометрический, квадратный      | ✓         | ~40 КБ/начертание |
| **Montserrat** | геометрический, нейтральный     | ✓         | ~50 КБ/начертание |
| **Exo 2**      | технологичный, конденсированный | ✓         | ~35 КБ/начертание |
| **Raleway**    | элегантный, тонкий              | ✓         | ~45 КБ/начертание |
| **Oswald**     | конденсированный, строгий       | ✓         | ~25 КБ/начертание |

Применение:

```less
// assets/css/fonts.less
@font-face {
    font-family: 'Unbounded';
    font-style: normal;
    font-weight: 700 900;
    font-display: swap;
    src: url('/fonts/unbounded-latin.woff2') format('woff2');
    unicode-range: U+0000-00FF, ...;
}
@font-face {
    font-family: 'Unbounded';
    font-style: normal;
    font-weight: 700 900;
    font-display: swap;
    src: url('/fonts/unbounded-cyrillic.woff2') format('woff2');
    unicode-range: U+0301, U+0400-045F, ...;
}
```

```less
// SectionHero.vue
&__name-line--accent {
    font-family: 'Unbounded', var(--font-sans);
    color: transparent;
    -webkit-text-stroke: 1.5px var(--text);
}
```

`font-size` и `font-weight` могут потребовать корректировки: Unbounded крупнее Inter при
том же `rem`.

**Плюсы:**

- Устраняет артефакты: геометрические глифы не имеют самопересекающихся сегментов
- Визуально усиливает Hero — отдельный шрифт для имени подчёркивает брендовый характер
- Прозрачный `color: transparent` продолжает работать — замена фона не нужна
- Тривиальная реализация: один `font-family` в одном CSS-правиле
- Самохостинг по схеме ADR 0017; на производительность влияет минимально (~80 КБ)

**Минусы:**

- Дополнительный шрифт в репозитории
- Потребуется визуальная подгонка `font-size`/`letter-spacing` под новый глиф
- Ритмика Inter (первая строка) и нового шрифта (вторая строка) может не совпадать —
  нужна проверка пропорций

---

### Вариант D — Системный шрифт без загрузки _(выбранный)_

Убрать Inter из `.hero__name-line--accent` и передать управление системному шрифту через стек
`system-ui, -apple-system, sans-serif`. Системные шрифты (SF Pro на macOS, Segoe UI Variable
на Windows, Roboto на Android) имеют геометрически более простые глифы без самопересекающихся
сегментов контура — артефакты при обводке исчезают или сводятся к минимуму.

```less
&__name-line--accent {
    font-family:
        system-ui,
        -apple-system,
        sans-serif;
    font-weight: 900;
    color: transparent;
    -webkit-text-stroke: 1.5px var(--text);
}
```

`font-weight: 900` сохраняется; если системный шрифт не имеет начертания 900, браузер
подберёт ближайшее доступное (на Windows — 700 Segoe UI Variable Bold, на macOS — SF Pro
Black 900).

**Плюсы:**

- Нулевые зависимости: не нужно скачивать файлы, добавлять `@font-face`, настраивать preload
- Мгновенно работает на всех платформах — системный шрифт уже в кэше ОС
- Нет FOUT: шрифт доступен до первого рендера
- Геометрически чистые глифы SF Pro / Segoe UI Variable устраняют артефакты
- Одна строка CSS

**Минусы:**

- Незначительное расхождение пропорций между платформами (SF Pro и Segoe UI имеют разные
  метрики); надпись может быть чуть крупнее или уже в зависимости от ОС — допустимо для
  декоративного элемента
- Поведение `font-weight: 900` варьируется: на Windows Segoe UI Variable может вернуть 700
  вместо 900; визуально это менее жирно, но всё равно выглядит корректно как outlined

---

### Вариант E — SVG-файл (предрендер)

Нарисовать надпись как статичный SVG-ассет вручную или через Figma, разместить в
`public/img/`, вставить как `<img>` или инлайн-SVG.

**Плюсы:** идеальное качество, полный контроль кернинга.

**Минусы:** не адаптируется под тему (нужно два файла для dark/light); при смене текста
(локаль, исправление) — ручная перегенерация; нет текстовой доступности без `aria-label`.
Отклонён как чрезмерно трудоёмкий.

## Принятое решение

Принят **Вариант D** — системный шрифт без загрузки. Вариант C (отдельный display-шрифт)
отклонён как излишний: проблема решается нулевой ценой, добавлять зависимость нет смысла.

### Чек-лист реализации

- [x] Добавить `font-family: system-ui, -apple-system, sans-serif` на родительский `&__name`
      в `SectionHero.vue` — оба `<span>` (имя и фамилия) наследуют шрифт без дублирования.
      `font-weight: 900` уже был на `&__name`, отдельно прописывать не потребовалось.

## Последствия

**Положительные:**

- Артефакты устранены без новых зависимостей и сетевых запросов
- Шрифт отрисовывается мгновенно — нет FOUT для этого элемента
- Минимальный диф: одна строка в одном компоненте

**Отрицательные / риски:**

- Незначительное расхождение пропорций между платформами; для декоративной надписи приемлемо
- На Windows `font-weight: 900` может быть отрендерен как 700 (ближайшее у Segoe UI Variable)
