Это первая запись в блоге. Сайт построен на **Nuxt.js 3** с поддержкой двух языков и генерацией статических страниц.

## О чём будет блог

Здесь я буду писать о разработке, инструментах и технологиях, которые использую в работе: Angular, TypeScript, архитектура SPA, процессы в команде.

## Стек сайта

Сайт собран на Nuxt 3 + `@nuxt/content` для статей и `@nuxtjs/i18n` для локализации. Деплой через GitHub Pages.

Конфигурация минимальная — весь контент в Markdown:

```ts
// nuxt.config.ts
export default defineNuxtConfig({
  modules: ['@nuxt/content', '@nuxtjs/i18n'],
  nitro: {
    prerender: { crawlLinks: true },
  },
  i18n: {
    defaultLocale: 'ru',
    strategy: 'prefix_except_default',
  },
})
```

### Почему SSG?

Статический сайт быстро грузится, не требует сервера и бесплатно хостится на GitHub Pages. Для блога и портфолио этого более чем достаточно.
